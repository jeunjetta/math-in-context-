# Twice as fast. But only ten milliseconds saved?

80-second silent visual draft; captions are the canonical script. The video
does not depend on the viewer knowing an FFT implementation.

| Seconds | Visual | Teaching purpose |
|---|---|---|
| 0–8 | Large 2× claim meets a not-equal sign; prediction prompt | Distinguish kernel from system |
| 8–18 | Fixed-scale 100 ms bar, Fourier 20 + other 80 | Establish the denominator |
| 18–30 | A second bar smoothly contracts only its Fourier segment | Preserve unchanged work; show 90 ms |
| 30–40 | 100/90≈1.11× and the general fraction formula | Quantify total speedup |
| 40–49 | Fourier block tends to zero; 80 ms remains | Reveal 1.25× ceiling |
| 49–61 | Four labelled cards | Separate complexity, stability, latency, readiness |
| 61–70 | Accuracy, data movement, deadline checklist | Engineering context, no operational promise |
| 70–80 | Concept chain, Marimo path and credited sources | Place the bite in the graph; invite exploration |

Direction: slate/navy background; teal improved work; amber unchanged work;
white headings; explicit labels so color is never the sole encoding. One
shared bar scale. Captions stay in a separate lower band. No copied creator
style, visual assets or soundtrack. No dramatic claims about solved problems.
