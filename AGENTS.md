# Math in Context contributor instructions

- Default to Marimo/Python experiments; add infrastructure for concrete needs.
- Preserve template examples and unrelated user changes.
- Public material only: no secrets, private notes, telemetry or operating models.
- Claims need assumptions and evidence labels. Resemblance is not a theorem.
- Cite primary material; link other creators and make original illustrations.
- Test numerical examples and feedback; label synthetic data.
- Run python -m unittest discover -s tests and Marimo check/export.
- Keep learner notebooks usable in WebAssembly without local servers or keys.
- Update ROADMAP.md only when deliverables actually complete.
- Prefer review branches and PRs. No force pushes or automatic merging.
